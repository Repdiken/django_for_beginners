# Django for Beginners – Practice Projects

This repository contains the source code for the projects I built while following **_Django for Beginners_** by **William S. Vincent**.

The book is a comprehensive, hands-on guide to building modern Python web applications with Django. It progresses step by step through six increasingly complex applications, covering core Django concepts such as:

- Models
- Views
- URLs
- Templates

It also introduces more advanced topics, including:

- User authentication
- APIs
- Testing
- Forms
- Permissions
- Security
- Performance
- Deployment
- Third-party packages

By the end of the book, you gain a solid understanding of how Django works and the ability to build real-world web applications efficiently and correctly.

---

## Repository Structure

Each chapter contains one or more projects corresponding to the material covered in that chapter.  
The goal of this repository is **learning and experimentation**, not polished production apps.
